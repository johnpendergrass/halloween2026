SIMPLE GAME RULES
-----------------
Candy is assumed sweet; Sweet is not a scoring attribute.
Fruity and Sour describe distinctive flavors, not an absence of sweetness.
Use 1-3 defining attributes per item; never add filler attributes.
Candy Bar is not a scoring attribute. Crispy is renamed Crunchy.
Sugar Free may be descriptive metadata, but is not scored in this proposal.
Every item starts with a base value of +1. Preference adjustments are added.
Characters currently use Strong like +2, Like +1, Dislike -1.
Strong dislike -2 is supported for later; no current profile uses it.
Unlisted attributes add 0 adjustment; a neutral item is worth +1 overall.
A character with no candy scores 0. A neutral six-item allotment scores 6.
Show the result of a proposed trade so the human does not need to do arithmetic.
For this untimed demo, show the raw sum, including negative values and totals above 10.
The top bar shows the combined score of all four characters.

--------------

Generic cookie and plain popcorn recipes are assumptions.

Toy items are neutral for the four current trial profiles.
