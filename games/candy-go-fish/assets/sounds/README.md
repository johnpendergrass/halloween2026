# Candy Go Fish audio

Active runtime audio: players-and-opponents/*.mp3, welcome-and-start-clicks/confirmText.mp3, indexed victory-announcements/*.mp3 and victory-sounds.js. startGameSpinner/spinnerDing.mp3 is retained for future use and currently silent.

Other WAVs, candidate recordings, name-only clips and announcer previews are local working sources, untracked in this checkpoint. Do not preload them. Preloading remains pending.

Character and confirmation effects came from John's Humble Bundle SoundSnap purchase, 2026 0806 HB Soundsnap 1000 SFX, UI User Interface pack. Originals are converted to 128 kbps MP3.

Victory voices were created by John at https://www.text-to-speech.online/en/ using NeerjaExpressive IN, normal speed, pitch -10%, MP3 output. Pronunciation text used Herm io ne for Hermione.

After adding or renaming victory files, run _documents/codex-john-docs/sync-victory-sounds.cjs from the repository root using its full path. See the current game handoff for naming and playback rules.
