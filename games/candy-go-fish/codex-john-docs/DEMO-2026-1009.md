# First playable demo — October 9, 2026

This update supersedes the original handoff's empty-hand/refill proposals. John clarified during implementation that **the game ends when either player runs out of active candies, or all sets are complete**. There are no refills. Some rounds consequently end with cards left in the pile. The demo judges the result by completed-set totals at that point.

Implemented: green card-table layout, fixed ten-slot boards, hidden Wendy hand with total count, selected candy in the center, separate Got Any? commitment, one-copy animated transfers, manual human fishing, Go Fish response to Wendy, fishing always passing the turn, automatic triples/checkmarks, random first player, five-card deals, early ending, score/result/replay, rules overlay, and cancellable New Game.

Empty identity images have 82% transparency by default; set `appearance.emptyCandyTransparency` to 100 to remove them. Occupied human slots show one/two candy images with badges. Wendy's unknown slots remain unidentified. Her private draw travels as a neutral wrapper rather than exposing its candy type. These visual treatments and strategy weights remain open to playtesting.

New `assets/json/game-config.json` owns the candy catalog, rules, timings, slot ordering, and transparency. A generated companion supports file opening; see that folder's README. None of the old game-data JSON/TXT files are loaded. Existing assets and mockups remain unchanged.

The pure engine enforces legal requests and early termination. Wendy receives a copy of her own type-only hand plus memory derived from public events, never the human hand or pile. Strategy uses weighted random choices: remembered possession helps, known absence hurts, and pairs receive an additional completion preference. A human draw clears absence evidence without revealing its type to Wendy.

Presentation resolves moves once and animates their events. Local overlays freeze pending timers and traveling candy; generation tokens invalidate work from discarded rounds. There is no dedicated Pause button, per John's direction; the game README documents the shared-requirement exception. No registry or shell modifications have been made. The centered `demo.html` previews the iframe shape separately from the shell.

Verification: engine scenarios and 1,000 reproducible games passed (maximum 42 requests in this run).
